# Glossário de edição e DTC

Termos que aparecem no OpenChatCut, no Premiere, no CapCut e no mercado de resposta direta.
O termo fica em inglês, como o mercado usa; a explicação fica em português.
Este arquivo cresce conforme a gente edita: termo novo que aparecer, entra aqui.

## Estrutura do editor

| Termo | O que é |
|---|---|
| **Timeline** | A linha do tempo: onde os clipes ficam em ordem, da esquerda (início) para a direita (fim). |
| **Track** | Uma trilha (faixa) da timeline. Trilhas de vídeo em cima cobrem as de baixo; trilhas de áudio tocam juntas. |
| **Clip** | Um pedaço de mídia colocado na timeline. |
| **Media pool** | A biblioteca do projeto: todos os arquivos importados, usados ou não. |
| **Playhead** | A agulha vertical que marca o ponto atual da reprodução. |
| **Preview** | A janela onde o vídeo toca enquanto você edita. |
| **Project** | O arquivo de trabalho com timeline, mídias e configurações. Não é o vídeo final. |
| **Aspect ratio** | Proporção da tela: 16:9 (horizontal, YouTube), 9:16 (vertical, Reels/TikTok), 4:5 e 1:1 (feed). |
| **FPS** | Frames per second: quantas imagens por segundo. 30 é o padrão de anúncio; 24 dá cara de cinema. |
| **Undo / Redo** | Desfazer / refazer. |

## Cortes e montagem

| Termo | O que é |
|---|---|
| **Cut** | Um corte: o ponto onde um clipe termina e outro começa. |
| **Trim** | Aparar o começo ou o fim de um clipe sem cortar no meio. |
| **Split** | Dividir um clipe em dois no ponto da playhead. |
| **Ripple delete** | Apagar um trecho e puxar tudo que vem depois para fechar o buraco. |
| **Jump cut** | Corte seco dentro da mesma cena (a pessoa "pula" levemente). Comum em UGC para tirar pausas. |
| **Rough cut** | O primeiro corte, grosso: a história na ordem certa, sem acabamento. |
| **Final cut** | A versão final, com acabamento completo. |
| **A-roll** | A filmagem principal, normalmente a pessoa falando. |
| **B-roll** | Imagens de apoio que cobrem o A-roll: produto, demonstração, cenas ilustrando o que é dito. Esconde jump cuts. |
| **Pacing** | O ritmo da edição: frequência de cortes e mudanças visuais. Anúncio costuma ter pacing rápido. |
| **Pattern interrupt** | Uma quebra visual ou sonora para segurar a atenção (zoom, som, mudança de cena). |
| **Multicam** | Várias câmeras gravando a mesma cena, sincronizadas, para alternar ângulos. |

## Visual e efeitos

| Termo | O que é |
|---|---|
| **Transition** | Efeito na passagem de um clipe para outro (fade, glitch, whip). Em anúncio, use pouco. |
| **Fade in / Fade out** | Aparecer ou sumir gradualmente (imagem ou som). |
| **Zoom in / Punch in** | Aproximar a imagem. Punch in é o zoom seco, usado para dar ênfase numa frase. |
| **Keyframe** | Um ponto marcado no tempo com um valor (posição, tamanho, volume). Entre dois keyframes o editor cria a animação. |
| **Motion graphics (MG)** | Textos e elementos gráficos animados: títulos, setas, números, destaques. |
| **Lower third** | Faixa de texto na parte de baixo da tela, geralmente com nome e cargo. |
| **Overlay** | Qualquer elemento colocado por cima do vídeo. |
| **Reframe** | Reenquadrar: adaptar de uma proporção para outra (ex.: 16:9 para 9:16) mantendo a pessoa no quadro. |
| **Chroma key** | Tirar o fundo verde (greenscreen) e colocar outro no lugar. |
| **Color grading** | Ajuste de cor para dar o "look" do vídeo. |
| **LUT** | Um "filtro" de cor pronto, aplicado de uma vez. |
| **Safe zone** | Área da tela onde texto não fica escondido pela interface do app (botões do Reels/TikTok). |

## Áudio

| Termo | O que é |
|---|---|
| **VO (voice-over)** | Narração gravada por cima das imagens. |
| **BGM** | Background music: a música de fundo. |
| **SFX** | Sound effects: efeitos sonoros (whoosh, click, pop). |
| **Ducking** | A música abaixa sozinha quando alguém fala e volta depois. |
| **Loudness / LUFS** | Volume percebido. Normalizar deixa todos os vídeos no mesmo volume (redes pedem por volta de -14 LUFS). |
| **Voice isolation** | Separar a voz do barulho de fundo. |

## Texto na tela

| Termo | O que é |
|---|---|
| **Captions** | Legendas que aparecem na tela, geralmente automáticas a partir da fala. |
| **Burned-in captions** | Legendas "gravadas" na imagem do vídeo final (não dá para desligar). Padrão em anúncio. |
| **SRT** | Arquivo de legenda separado do vídeo. |
| **Transcript** | Transcrição: o texto de tudo que foi falado, com o tempo de cada palavra. |
| **Filler words** | Vícios de fala: "é...", "tipo", "né", "ahn". A edição remove. |

## Exportação

| Termo | O que é |
|---|---|
| **Export / Render** | Transformar o projeto no arquivo de vídeo final. |
| **Codec** | O formato de compressão do vídeo. H.264 (MP4) é o padrão universal. |
| **Resolution** | Tamanho da imagem: 1080p (1920x1080) é o padrão; em vertical, 1080x1920. |
| **Bitrate** | Quanto de dados por segundo. Mais bitrate, mais qualidade e arquivo maior. |
| **XML / FCPXML** | Arquivo que leva a timeline para outro editor (Premiere, DaVinci) para terminar lá. |

## DTC e resposta direta

| Termo | O que é |
|---|---|
| **DTC** | Direct-to-consumer: marca que vende direto para o cliente, sem loja no meio. |
| **Direct response** | Publicidade feita para gerar uma ação imediata (clique, compra), e medida por isso. |
| **VSL** | Video Sales Letter: vídeo de vendas longo que substitui a página de vendas escrita. |
| **Lead (de VSL)** | A abertura do VSL: os primeiros minutos que prendem e fazem a pessoa continuar assistindo. |
| **Micro lead** | Um lead curto, usado como anúncio ou para testar aberturas antes de gravar o VSL inteiro. |
| **Hook** | O gancho: os primeiros 1 a 3 segundos que fazem a pessoa parar de rolar. |
| **Hook rate** | Porcentagem de pessoas que assistem aos primeiros ~3 segundos. Mede a força do hook. |
| **Hold rate / Retention** | Quanto tempo as pessoas continuam assistindo depois do hook. |
| **CTA** | Call to action: a chamada para ação ("clique no botão abaixo"). |
| **Upsell** | Oferta extra apresentada depois da compra, normalmente em vídeo curto. |
| **Downsell** | Oferta mais barata mostrada para quem recusou o upsell. |
| **Funnel** | O caminho do cliente: anúncio → VSL → checkout → upsell. |
| **UGC** | User-generated content: vídeo com cara de gravado por cliente comum, com celular. |
| **Angle** | O ângulo: a razão principal que o anúncio usa para vender (dor, resultado, novidade...). |
| **Creative** | O anúncio em si (vídeo ou imagem). "Testar criativos" = testar anúncios diferentes. |
| **Variant** | Uma variação de um criativo (outro hook, outra ordem, outro formato) para teste A/B. |
| **Big idea** | A ideia central e diferente que sustenta a campanha inteira. |
| **Mechanism** | O "mecanismo": a explicação de por que o produto funciona, e por que é diferente. |
| **Proof** | Prova: depoimento, demonstração, número, antes e depois. |
| **Compliance** | Regras das plataformas de anúncio. Promessa exagerada (saúde, dinheiro) derruba a conta. |
